# Composio Workspace

Composio integration plugin for Sameer AI Workspace.

## What it provides

- Dynamic discovery of connected Composio apps
- OAuth-based connection management
- Multiple connected accounts per toolkit
- Runtime tool/schema discovery
- Real tool execution through Composio MCP
- No hardcoded app or action mappings

## MCP endpoint

https://connect.composio.dev/mcp

The workspace's existing Composio OAuth flow provides the authenticated session used by the application.
